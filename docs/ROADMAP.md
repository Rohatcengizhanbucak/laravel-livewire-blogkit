# Roadmap

## 0.1 Foundation

- Laravel 13 and Livewire 4 application shell
- Authentication starter kit
- Content, locale, SEO, theme, and palette models
- Migrations and starter seed data
- CI for tests and linting
- Open-source repository health files

## 0.2 Public Blog + Google SEO

- Public post index
- Post detail pages
- Category and tag pages
- Published/draft/scheduled visibility rules
- Locale-aware route resolution
- SEO meta rendering with title, description, robots, Open Graph, and JSON-LD
- Canonical URL support
- `hreflang` and `x-default` alternates
- Dynamic `/sitemap.xml`
- Dynamic `/robots.txt`

## 0.3 Admin Publishing

- Post create/edit flow
- Page create/edit flow
- Translation management
- Category and tag management
- Preview mode
- Scheduled publishing

## 0.4 Themes

- Default public theme
- Minimal theme
- Magazine/editorial theme
- Dynamic palette selection
- Theme configuration UI

## 0.5 Advanced SEO

- RSS/Atom feeds
- Redirect manager
- Social preview image workflow
- Search Console oriented reporting hooks

## 1.0 Stable Release

- Documented extension points
- Upgrade guide
- Import/export tools
- Production deployment guide
- Accessibility pass
- Performance budget
