# Security Policy

## Supported Versions

This project is in early foundation status. Security fixes are accepted for the `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Email the maintainer or use GitHub private vulnerability reporting if enabled for the repository. Include:

- affected version or commit
- reproduction steps
- expected impact
- any suggested fix

We will acknowledge valid reports as quickly as possible and coordinate a fix before public disclosure.
